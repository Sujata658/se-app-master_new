# ICTC Web CMS
This is a web cms web app developed for ICTC Pulchowk Campus. 

## Features
  ### Client Side:
    - Home, Services, Events, Contact and Login Page
    - Can reserve dates for reservation
  ### Admin Portal and Dashboard:
    - CRUD of Events, Services
    - Can add multiple events page similar to CMS
    - Approve, reject, confirm reservations
